✉️ Kontaktformular – Benachrichtigung

Wer soll eine E-Mail bekommen, wenn jemand das Kontaktformular abschickt? Es können zwei Personen eingetragen werden. Ein Feld leer lassen, wenn nur eine Person benachrichtigt werden soll. Die Anfragen stehen außerdem immer im Admin unter „Anfragen“.

Die Test-Mail geht an die gespeicherten Adressen – also erst speichern. Sie kommt von noreply@hafo.de; bitte notfalls im Spam-Ordner nachsehen.
